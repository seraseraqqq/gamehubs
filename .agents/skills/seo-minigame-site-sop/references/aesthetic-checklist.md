# Aesthetic Checklist — Mandatory Before Final Output

## Visual Hierarchy
- [ ] Game is the single dominant element above the fold
- [ ] Title is clear but not oversized
- [ ] No hero sections with large decorative images competing with the game

## Layout Discipline
- [ ] Maximum 2 nesting levels of containers
- [ ] No card grids unless showing related games (and even then, sparse)
- [ ] Generous margins around the game canvas

## Text Restraint
- [ ] How to Play ≤ 40 words
- [ ] No long paragraphs of "about this game" filler
- [ ] FAQ limited to 3 short Q&As if present

## Color & Typography
- [ ] Palette limited (prefer dark bg + 1-2 accent colors)
- [ ] High contrast for readability
- [ ] System font stack or one clean typeface

## Forbidden Patterns
- Nested rounded cards with shadows
- Multiple bordered sections stacked vertically
- Walls of text under the game
- Decorative icons or illustrations that do not serve gameplay

## Reference Alignment
Before shipping, compare the generated page against at least two of the sites listed in `reference-sites.md`. The result should feel closer to those examples than to a typical AI-generated landing page.
