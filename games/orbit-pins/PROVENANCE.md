# Pinlark: sources and scope

Original project code, artwork and 30 level configurations were authored for this GameHubs implementation. No third-party game bundle, original game's level table or official clue archive was imported. The original code/content are MIT licensed; that does not grant third-party trademark rights.

Figtree Latin is copied from the already documented Google Fonts subset in this workspace, under SIL OFL; its full notice is in assets/fonts/Figtree-OFL.txt. Georgia / Times are system fallbacks, not bundled fonts. All runtime assets are local. There are no ads, analytics or API calls.

The rotating-pin concept is shared with games such as Coreball, but this is not the original Coreball product.

Brand/domain availability research is not trademark clearance. No domain is purchased or used as a production canonical until the owner confirms it. Preview builds remain noindex.
