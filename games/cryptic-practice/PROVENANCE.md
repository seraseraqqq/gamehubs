# Clue Garden: sources and scope

Original project code, artwork and 20 clue phrasings, hint sequences and explanations were authored for this GameHubs implementation. No third-party game bundle, original game's level table or official clue archive was imported. The original code/content are MIT licensed; that does not grant third-party trademark rights.

Figtree Latin is copied from the already documented Google Fonts subset in this workspace, under SIL OFL; its full notice is in assets/fonts/Figtree-OFL.txt. Georgia / Times are system fallbacks, not bundled fonts. All runtime assets are local. There are no ads, analytics or API calls.

This is an independent cryptic practice bank, not affiliated with Minute Cryptic. Letter recipes and metadata are validated automatically; no external professional crossword-editor review is claimed.

Brand/domain availability research is not trademark clearance. No domain is purchased or used as a production canonical until the owner confirms it. Preview builds remain noindex.
