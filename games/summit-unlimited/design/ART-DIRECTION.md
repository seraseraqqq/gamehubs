# STARLING · 像素科技美术与动态场景改版

日期：2026-10-23

## 为什么上一版像贴图

1. **资源切分错误。** 风景、光照、远近关系都绘制在一张全屏画里。放大、漂移和淡入淡出只能移动整张图片，不能表现物体之间的相对运动。
2. **缺少环境循环。** 运动主要发生在提交答案之后；等待输入时，世界几乎停止。画面需要低频环境运动、主体动作和事件反馈三个不同节奏。
3. **视觉语法不统一。** 绘画背景、光滑的界面、发光按钮与不同细节密度的火箭混在一起。背景比题目复杂，文字与景物争夺注意力。
4. **构图没有保护交互。** 大尺寸场景画在移动端裁切后，主体、输入栏和题目会互相遮挡；仅依赖桌面静态图无法发现这些问题。

参考截图值得借鉴的是受控的细节、明确的文字层级，以及独立运动的环境物体。改版保留太空主题，以原创像素素材重新组织场景。

## 统一规则

- 主色：深空蓝 #081529、面板蓝 #0C1D31、青色 #8FE3E1、珊瑚红 #FA7183、米白 #EDF2DB。
- 蓝色和灰色承载环境；青色标识信息与输入；红色标识主要动作、当前航段和分数。
- 场景在约三分之一屏幕分辨率的 Canvas 绘制，最近邻放大。素材先经过透明边缘阈值和有限色量化；行星使用较高的源精灵分辨率，避免放大后丢失辨识度。
- HUD 和题目使用本地 Silkscreen 字体，说明文字使用等宽字体。所有文字均由 HTML 绘制；扫描线只叠加在场景之上。
- 题目使用深色实底卡片。输入区域与主体、星体分开布局。手机场景预留底部控制区，避免火箭被输入框遮住。
- 边框、按钮、状态指示、网站图标统一为直角与阶梯切角。

## 持续运动

| 场景 | 独立图层和循环 |
| --- | --- |
| 发射台 | 云层分速漂移、服务灯闪烁、蒸汽移动、独立火箭 |
| 大气层 | 地球近景、云层、缓慢绕行的卫星、背景星点 |
| 月球 | 月球前景、远处地球、漂浮卫星、掠过的流星 |
| 火星 | 火星近景、小行星、上下漂浮的信标 |
| 木星 | 巨大木星、两颗不同运动周期的卫星、探测器 |
| 太阳系 | 轨道、太阳、四颗不同公转速度的行星 |
| 银河系 | 缓慢转动的星系、小星系、横向漂移的小行星带 |
| 宇宙边缘 | 星系与缓慢起伏的宇宙网节点、背景星点 |

飞行时，火箭持续轻微浮动，尾焰按帧变化，粒子以不同速度脱离尾部。各图层不共享一个整体位移动画。

## 转场与反馈

- **地面 → 大气层：** 地面向下离开，火箭爬升，云幕经过镜头，尾焰变长，星点拉伸。
- **大气层 → 月球 → 火星 → 木星：** 上一个地标侧向离开，下一个地标从前方掠入；用前后景相对运动表达经过天体。
- **木星 → 太阳系 → 银河系 → 宇宙边缘：** 原来的世界缩小，镜头拉远到更大尺度的场景，避免把尺度切换都处理为向上平移。
- 答题反馈先显示得分，再开始航段动画；转场期间锁定输入，结束后才开始下一题的 25 秒计时。
- 距离是压缩叙事的里程；分数单独显示。稀有度目前来自本地题库与简单估计，不声称来自实时玩家统计。
- 尊重系统减少动态设置：停止环境循环、缩短转场，保持相同航线和答题流程。

## 资源与边界

`pixel-flight-direction.png` 是本轮生成的方向图，不是运行截图。`assets/pixel/*-source.png` 保留生成源图；运行精灵由 `scripts/prepare_assets.py` 派生。游戏中不使用旧版全屏绘画背景。

音频包括浏览器合成的环境和弦、稀疏旋律、答案提示与推进器扫频，用户开启声音后播放。当前没有专门录制的发动机声或完整编曲的音乐曲目。下一步如需进一步提高成品感，应投入在火箭姿态精灵、天体表面运动和声音设计上，而不是增加背景画的细节。
