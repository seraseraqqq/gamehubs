A few useful answers

Is Acceleration City free to play?

The original browser game can be opened without a payment on the CS2N activity page. This independent page adds a focused view and player help. The game is created by Carnegie Mellon Robotics Academy.

What is the CoBot?

Your CoBot is a programmable partner. Its actions can be linked to keyboard inputs or colored areas on a track. Build and test a small program in the game's Blocks editor; the action is determined by your program, rather than one universal shortcut.

Do I need an app or a download?

The game runs in a browser using WebGL. Its game files download as part of loading the page. This site does not offer an APK or a separate desktop app. For an Hour of Code lesson, use the official Carnegie Mellon Robotics Academy resources.
