The user requested a keyword-led game site for **acceleration city**, using the same technical approach as the observed competitors, with a better play wrapper and accurate search content. On October 24, 2026, the user selected a **simple dark appearance that emphasizes the original game**.

This surface embeds the original CS2N activity, which is a Unity WebGL game with a React/Scratch-style Blocks programming interface. Its differentiating mechanic is the programmable CoBot, not merely city driving. The wrapper does not reproduce, proxy or alter the original engine, art or account state.

The immediate deliverable is a local evaluation prototype, not a public deployment. The game shows “For educational use only”; commercial embedding rights are unknown. Production export requires both a real SITE_ORIGIN and an explicit GAME_EMBED_LICENSE_CONFIRMED=true. Setting a flag does not obtain permission.

Primary visitor task: start the original browser game, use a large distraction-free viewport, and find accurate help without an ad or unrelated game grid blocking the view. Desktop keyboard play is the supported recommendation; the shell is responsive but does not add mobile controls to a cross-origin game.

Success is a usable original game embed, explicit load/recovery states, focused/fullscreen presentation, truthful CoBot instructions, and crawlable metadata when a licensed production release is configured. No rankings, traffic, 2-second Unity load, save synchronization, multiplayer or touch support are promised.
