About this Cluster Rush site

This is an independent fan page for playing Cluster Rush in a browser. The website provides a focused player, keyboard reference, fullscreen controls and practical help.

Where the game comes from

The game is an external, unmodified Unity build embedded from clusterrush.io. That page currently loads game resources from GitHub Pages. We did not develop the original game, and do not claim affiliation with its developer or those hosts.

The website’s code and help content are separate from the embedded game. The game remains controlled by its host; loading, availability, saved progress and future changes can depend on that service.

Accuracy and feedback

The opening level, controls and loading chain were inspected on October 24, 2026. We do not claim that every level or every phone has been tested. Send website problems or rights inquiries through the project issue tracker. Avoid posting private information in a public issue.
