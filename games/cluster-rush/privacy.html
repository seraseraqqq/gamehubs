Privacy

Updated October 24, 2026.

This website

This version has no sign-up, comment form, advertising script, or website analytics script. The page controls do not store personal information or game progress. The hosting service may process ordinary request data such as IP address, browser information and access logs.

Embedded game

The game loads automatically inside an iframe from clusterrush.io. Its page currently requests Unity resources from freegamesonlinee.github.io. Those requests expose ordinary connection information to the external services. Their code, logging and browser storage are controlled by them and may change independently.

We cannot inspect or erase cross-origin game storage from the surrounding website. Use your browser’s site-data settings to review or remove it. Doing so can affect saved progress.

External links and inquiries

Links to the game provider and GitHub open external services with their own policies. For a website or privacy inquiry, use the project issue tracker. Do not include sensitive personal information in a public report.
