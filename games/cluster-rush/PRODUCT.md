# Cluster Rush

English single-game browser website for search visitors who want to play Cluster Rush immediately, understand the real controls, or fix a failed load. Existing Unity iframe architecture is a user requirement. This is an independent fan website, not a claim of original game development.

Experience mode: the playable game is the main surface. Desktop keyboard first; no touch success or high-score integration claims. Preserve game control isolation. Local deliverable only until an owned domain and embedding rights are resolved.
