# 游戏复刻单站选词 SOP

> 目标：选出**高量、低竞争、可复刻、能稳定出流量**的词，避免再做一堆没流量的薄站。

## 整体原则

- **主力（70–80%）**：Semrush / Ahrefs 挖的老词
- **辅助（20–30%）**：findnews 新游戏当灵感，必须再验证
- **必须同时满足**核心条件才建站，缺一不可

---

## 第一步：初始挖词

**工具**：Semrush（或镜像）、Ahrefs、findnews（仅灵感）

**操作**：

1. 在 Semrush 搜索游戏相关种子词，或直接看竞品站点的排名关键词。
2. 过滤条件：
   - 月搜索量 ≥ 1.5万（优先 ≥ 2万）
   - KD ≤ 25（优先 ≤ 20）
   - 国家优先美国 / 英语国家
3. 从 findnews「新游戏」板块挑感兴趣的游戏名，丢进 Semrush 查搜索量和 KD。

**输出**：初步词表（Excel / CSV），标记来源。

---

## 第二步：竞争与可复刻验证（最关键）

对每个候选词做以下检查：

| 检查项 | 标准 | 不通过处理 |
|--------|------|------------|
| **真实搜索量** | Semrush / DataForSEO 确认 ≥ 1.5万 | 淘汰 |
| **KD** | ≤ 20 | 淘汰或降优先级 |
| **SERP 前 10** | 打开 Google 实际搜索，看前 5–10 名 | 必须人工看 |
| **可超越性** | 前排有薄内容页、纯目录、老页面、广告站 | 有明显弱页面才保留 |
| **意图清晰** | 用户是来玩这个游戏的，不是纯新闻/一次性热点 | 淘汰 |
| **可嵌入** | 能找到可合法嵌入的版本（WebGL / iframe / 官方 demo） | 优先保留 |

### 快速判断技巧

- 前排大量是「游戏名 + unblocked / play online」的薄站 → 有机会
- 前排是强站 + 高质量内容 → 放弃
- 搜索结果全是新闻或论坛 → 意图不对，放弃

---

## 第三步：二次筛选与优先级

用以下权重打分（可选）：

| 因素 | 权重 | 说明 |
|------|------|------|
| 搜索量 | 30% | 越高越好 |
| KD | 25% | 越低越好 |
| SERP 可打性 | 30% | 人工判断最重要 |
| 可复刻难度 | 15% | 容易嵌入 + 好写内容优先 |

### 优先级划分

- **优先做**：搜索量高 + KD ≤ 18 + SERP 明显可打 + 易嵌入
- **可做**：搜索量中等 + KD ≤ 22 + SERP 有机会
- **放弃**：任何一项明显不达标

---

## 第四步：建站前最终确认

建站前再确认一次：

1. 这个词不是纯短期热点（Google Trends 看是否持续有量）
2. 你能做出比前排更好的页面（嵌入 + 800–1500 字有价值内容 + FAQ）
3. 域名可注册或已有匹配域名
4. 准备好基础内容结构（玩法、操作、FAQ、相关推荐）

**通过才建站，否则放回观察列表。**

---

## 工具组合推荐

| 环节 | 工具 | 用途 |
|------|------|------|
| 挖词 | Semrush / Ahrefs | 主力 |
| 灵感 | findnews | 只看新游戏名 |
| 验证 | DataForSEO + 实际搜索 | 确认搜索量和 SERP |
| 趋势 | Google Trends | 排除纯尖峰 |
| 记录 | Excel / Supabase | 记录筛选结果和状态 |

---

## 常见淘汰原因

- 只看搜索量和 KD，没认真看 SERP
- 内容太薄，页面只是加载器
- 选了意图不清晰或稳定性差的词
- 批量上站，没有逐个验证

---

## 执行建议

先用这个 SOP 把现有词表重新筛一遍，只留下真正符合标准的词，再继续上新站。**质量优先于数量。**

目标不是 5 个月做 200 个薄站，而是做 50–80 个能真正有流量的合格站。
