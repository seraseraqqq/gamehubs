# 挖词、复筛与证据

## 开始与来源

从用户范围、当前词池和已知竞品确定种子；用户未给种子时先利用可读的GameHubs／连接上下文，说明拟研究的小批范围再推进，只有确实缺少必要信息才询问。已有词表全部保留，原词、拼写纠正和近义词用关联表达，不覆盖历史身份。

老词／竞品已有排名词为主（研究资源约70–80%）；新游戏名仅作灵感（20–30%），不以findnews条目、发布日期或社交热度作为搜索需求证明。按用户要求的覆盖量推进，不为凑合格数扩大范围。

优先站主免费Semrush镜像`https://sem.3ue.com/analytics/keywordoverview/?db=us`及现有访问。Ahrefs只用已有访问；自部署OpenSEO和DataForSEO可补充。其他环境中未提供镜像／账号时使用确实可用的来源并披露差异，不声称已使用镜像。连接的OpenSEO不一定是站主自部署实例，先确认实例与数据上游，不能只看工具名。

保存provider、数据库／指标方法、国家／语言、目标关键词、采集日期、来源数据日期、显示值和原始返回。Volume为工具估值，KD为该工具指标；不同工具KD不能直接按同一尺度拼接。冲突保留各方值及主用来源，不取有利的一方制造通过；共享上游的两个入口不算独立验证。付费调用复用有效证据、核对已有预算和范围，只有超出已有授权才询问；超时可能已计费，不盲目重试。

## 分档

先以Volume≥15,000、KD≤25初筛。后续分档是附件KD≤20与“可做”≤22的明确执行解释：

| 结论 | 数值 | 其他条件 |
|---|---|---|
| 优先候选 | Volume≥20,000且KD≤18 | 全部证据条件成立；低成本合法实施优先 |
| 主候选 | Volume≥15,000且KD≤20，不属于优先档 | 全部证据条件成立 |
| 条件候选 | Volume≥15,000且20<KD≤22 | 更明确竞争切口、差异与成本理由，供站主独立决定，不计入主候选 |
| 观察 | Volume≥15,000且22<KD≤25 | 只过初筛，不进默认建设队列 |
| 未达标 | 已知Volume<15,000或KD>25，或关键条件明确不成立 | 保留原因及缺项；不删除历史或自动下线旧站 |
| 待验证 | 判断必需证据缺失／冲突，且无独立明确淘汰原因 | 保留unknown，不伪造通过 |

其他条件为真实Google可超越性、直接游玩意图、持续需求、具体版本、合法可实施路径和页面改善。候选数值过线但许可未知，应为待验证，不能标主候选。已知月量不足，即使另一指标未知，仍可记录明确的量不足与其他缺项。

附件可选评分权重为Volume30%、KD25%、SERP30%、实施难度15%。不必强制评分；如用，先写统一各项评分尺度、得分和理由，仅用于过关者排序，不能将原始Volume与KD直接相加或让总分抵消条件未过。

## Google与实际页面核查

浏览器查看当前Google前5–10条自然结果，默认`gl=us&hl=en&pws=0`。实际只见7条就记录7条，不补造完整前十；参数不证明物理美国位置。广告、视频、AI模块与自然结果分开；API或镜像快照保留为其本身，不能冒充本次浏览器观察。

逐条保存位置、标题、URL、页面形态、对应游戏版本、主要功能、可核实弱点和拟改善。访问关键竞品，核实其已有practice／unlimited／solver等能力，不把现成功能宣称成空白。混合意图不能把整个词量全部归给游戏。短正文可能是游戏已满足需求；目录、旧内容、广告和unblocked只是核查线索。前排强且没有具体改善切口则退出默认队列；描述可比较的页面与体验，不能只写“竞争合理”。

实际尝试开始、输入、胜负／结束和重玩；只核对规则或首页加载时明确限制，不声称完整试玩通过。嵌入受限、验证码或访问失败记录为缺口，不绕过限制或默认仍可用。无法完成某步骤时保存部分结果，继续独立可做的部分。

## 趋势及实施最终核实

Google Trends：US、Web Search、过去12个月，必要时补90天／5年。保存原始词、曲线、时间窗口、采集时间；按季节性、持续平台、衰退或纯尖峰说明判断。稳定老词可以通过，不要求增长。指数归一化、低采样0不等于无需求，不同图指数不能直接比较；证据不足为未知。

分别核实游戏版本与意图、代码／素材／数据许可、嵌入发布方条件、目标域／触屏限制、外部服务及维护成本。优先合法低成本嵌入；独立自研只能在同样搜索机会已证明后作为方案，不从公开仓库或能打开iframe推断商用权限。

KGR／intitle保留已有公式和来源作为辅助，不强制补采、不设默认淘汰线、不用allintitle代填intitle。历史量>10,000／KD<30、量>3,000／KD≤30、KGR与上涨门槛及旧S/A/B/C，仅解释原批次；新研究注明SOP版本`2026-10-29.1`，不能直接沿用旧评级。
