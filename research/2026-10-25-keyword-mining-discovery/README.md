# 公开来源候选发现 · 2026-10-25

本轮只发现候选，未查询共享Semrush账号、未操作Chrome、未写入正式data或生成索引。交付 [candidates-public.json](candidates-public.json) 共 **150个独立查询词**，按当时generated/hub.json的140词去重，保留来源、发现线索、词簇提示和意图/版本风险。名称中的 `.io` 有的转换为空格查询；`waffle game`、`framed game`、`cell tower game`、`quintessential game` 为消歧查询表达，不另算原作名称或需求变体叠加。

## 与主任务的关系

用户要求US/en、Volume>3000、Google Trends上升、KD<=30、标准KGR<=0.25且SERP竞争合理。**这150词没有一项被本发现环节宣布达标**：没有凭平台排序、点赞数、更新时间或“Trending”标记猜测Google趋势，没有编造Volume/KD/allintitle。合格与否由主线按实测指标和SERP证据逐词判定。低量、失败、被拒或未知均须保留；同词簇不重复立站，也不把许可未知当许可通过。
