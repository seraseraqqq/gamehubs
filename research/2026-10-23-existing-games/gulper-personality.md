# Gulper：拟人电脑对手更新

日期：2026-10-23（Asia/Shanghai）。本地验证已完成，纳入用户授权的 GitHub 发布批次；线上部署需单独核验。

按用户决定，产品长期保持单人电脑对手模式，不开发多人联机。拟人化体现在行为与风格，不伪装真实在线玩家。

## 已实现

- 18 个独立昵称的电脑对手，四种打法：采集型、猎手型、游走型、新手型。
- 有限附近感知、错开的反应间隔、短暂目标坚持、偶发延迟和转向误差；不会全图锁定玩家。
- 采集与争抢高价值食物；猎手会尝试短距离预判截击；看到较大对手靠近会退让；危险路径绕行，边界附近停止冲刺并回场。
- 对手相互竞争，不只追玩家。受保护的新生对手和很小的初始蛇不作为猎手新目标。
- 冲刺分为短脉冲与休息期，消耗同样的质量，沿用与玩家相同的移动、转向、碰撞和生长规则。
- 阵亡后经过不同等待时间返回，保留昵称、皮肤和打法；新一局清空旧复活队列，不会多刷或重复身份。
- 补充可见说明与对应 FAQ 结构化数据；移除报告中待评估多人模式的建议，项目库存保存明确的单人产品决定。

复查时另修复：真实游戏开始后隐藏开场装饰蛇；手机 HUD 与局部排行避让；玩家撞边界的结算被正常报告，且同一死亡只安排一次结算。

## 验证

- `node --test games/gulperio/tests/*.test.cjs`：18 / 18 通过。
- 固定种子的 3600 帧实际竞技场逻辑模拟：观察到 forage、wander、hunt、avoid、flee、return、contest 七类状态，21 次复活，13 个对手发生过对其他电脑对手的追击。存活电脑对手始终不超过 18 且身份无重复。模拟不包含绘制，不能解释为真实帧率或性能承诺。
- 实际 Chromium 浏览器约 12.2 秒、121 次抽样：四种性格均存在，观察到上述七类状态与冲刺、对其他电脑对手的追击。该次随机样本没有追击玩家，不代表所有局都不会追击玩家。
- 手机开局时 HUD 保持在竞技场内，未出现页面横向溢出；开局背景不再显示装饰蛇。桌面与手机截图已检查。
- 用边界死亡场景检查真实浏览器结算显示；未观察到 JS 页面错误。
- 原有 106 项静态 SEO / 导出检查继续通过，`bot-brain.js` 被包含在正式运行包内，测试和研究文件不发布。

时间参数仍采用原引擎的帧计数，低帧率设备上反应、冲刺和等待的实际时长会变化。本次未重写物理时步，也未进行真机 Safari 验证。拟人手感仍应通过实际试玩反馈继续微调。
