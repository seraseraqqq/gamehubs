# 六个游戏的域名匹配与采购优先级

核验日期：2026-10-25（Asia/Shanghai）。本轮仅查可注册性与匹配度，没有购买、预留域名或发起付款。

需求判断复用 2026-10-24 的 US/en 完整研究；Volume/KD 是用户提供的免费 Semrush 镜像估值，不是本轮新采集或官方认证。Trends 比较只看同一词自己的变化，不跨不同图比较绝对指数。unlimited/practice 等变体没有独立的量/KD，不能直接套用主词估值。Minute Cryptic Unlimited 不在该 117 词研究中，暂无同口径独立量/KD。

## 可注册性与价格的来源分开

- [全部45个查询结果](domain-checks.json)：Vercel Registrar API 当次实时返回。表中候选全部 `available=true`、`premium=false`。`available=false` 仅记为未确认可注册，不把接口失败和被注册混为一谈；未采用这些结果作为推荐。
- Poople 的 poopleunlimited.com、playpoople.com，以及根域 poople.xyz / .top / .online 本次未确认可注册，因此没有推荐为可购。
- API JSON 中的金额是 **Vercel 报价**：例如 .com US$11.25/年、.top US$9/年，不能冒充 Spaceship 的价格。
- Spaceship 普通非溢价后缀的当前基础价参考如下，实际某个完整域名的结账价、优惠资格及附加费以购买时为准。

| 后缀 | 首年 USD | 续费 USD/年 | 官方价目 |
|---|---:|---:|---|
| .com | 8.88 | 9.98 | https://www.spaceship.com/domains/ |
| .xyz | 1.86 | 13.77 | https://www.spaceship.com/domains/gtld/xyz/ |
| .top | 1.40 | 3.85 | https://www.spaceship.com/domains/gtld/top/ |
| .online | 0.98 | 15.08 | https://www.spaceship.com/domains/gtld/online/ |

.com/.online 通常另加页面列示的 ICANN US$0.20/年。便宜试验中，.top 的普通续费低于本次 .xyz/.online 价目；.online 首年便宜，续费未必便宜。价格随时可变，不能把后缀基础价当作某个具体名称的锁价。

后缀本身不带 Google 排名加分：[Google 官方说明](https://developers.google.com/search/help/site-position-in-search-faq)。选择 .com 的理由是名称习惯与长期经营安排，而不是买后缀就能拿排名。
